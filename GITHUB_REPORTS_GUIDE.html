🎭 View Test Reports on GitHub

Complete Guide to Accessing Your Playwright Test Reports

⚠️ Current Situation: Test scripts are on GitHub, but reports are not visible because they are generated at runtime, not stored in the repository.
✅ Solution: Set up GitHub Actions to automatically run tests and generate reports on every push/PR!

🚀 Option 1: GitHub Actions

RECOMMENDED

Automatic Test Execution with Reports

Set up a workflow that automatically runs tests and generates reports whenever you push code or create a pull request.

What You Get:

  • Automatic test execution on every push
  • All 4 report types generated (HTML, JSON, JUnit, Console)
  • Downloadable artifacts from GitHub Actions
  • PR comments with report links
  • Test summary in workflow page
  • Screenshots and videos on failure

Setup Steps:

Step 1: Create Workflow File

Create a new file in your repository:

Path: .github/workflows/playwright-tests.yml

Method A - GitHub UI:

  1. Go to your repository on GitHub
  2. Click "Add file" → "Create new file"
  3. Type the path: .github/workflows/playwright-tests.yml
  4. Copy content from GITHUB_ACTIONS_WORKFLOW.yml in your repo
  5. Commit the file

Step 2: Trigger the Workflow

Automatic Triggers:

  • ✅ Push to main, feature/*, or test/* branches
  • ✅ Pull requests to main branch

Manual Trigger:

  1. Go to "Actions" tab
  2. Click "Playwright Tests with Reports"
  3. Click "Run workflow" button

Step 3: Download Reports

After workflow completes:

  1. Go to "Actions" tab
  2. Click on the completed workflow run
  3. Scroll to "Artifacts" section at bottom
  4. Download:
    • playwright-html-report - Interactive HTML report
    • playwright-json-report - JSON results
    • playwright-junit-report - JUnit XML
    • test-screenshots - Failure screenshots
    • test-videos - Test execution videos

Step 4: View HTML Report

# Extract the downloaded ZIP
unzip playwright-html-report.zip

# Open in browser
open index.html        # Mac
start index.html       # Windows
xdg-open index.html    # Linux

🌐 Option 2: GitHub Pages

ADVANCED

Publish Reports to Public URL

Deploy your HTML report to GitHub Pages for easy sharing with your team.

Benefits:

  • Live URL to share reports
  • No download required
  • Always shows latest results
  • Professional presentation

Enable GitHub Pages:

  1. Go to repository Settings
  2. Click Pages in sidebar
  3. Under Source, select: GitHub Actions
  4. Click Save

Your reports will be published at:

🔧 Troubleshooting

"I don't see the Actions tab"

Go to: Settings → Actions → General → Enable "Allow all actions"

"Workflow is not running"

  • Check if file is at .github/workflows/playwright-tests.yml
  • Verify branch name matches trigger pattern
  • Check workflow syntax is valid YAML

"Can't download artifacts"

  • Artifacts expire after 30 days
  • You must be logged in to GitHub
  • Check if workflow completed successfully
