🔧 TROUBLESHOOTING:

Problem: "I don't see the Actions tab"
Solution: Settings → Actions → General → Enable actions

Problem: "Workflow not running"
Check:   • File is at .github/workflows/playwright-tests.yml
         • YAML syntax is valid
         • Branch name matches trigger pattern (main, feature/*, test/*)

Problem: "Tests failing in workflow"
Solution: • Check workflow logs for error messages
         • Run tests locally first: npm test
         • Verify playwright.config.ts is correct

Problem: "Can't download artifacts"
Check:   • You're logged in to GitHub
         • Workflow completed (even if tests failed)
         • Artifacts haven't expired (30 day retention)

Problem: "HTML report is empty"
Solution: • Check if tests actually ran
         • Verify reporter configuration in playwright.config.ts
         • Look for errors in workflow logs
