📊 Report Type 1: HTML Report (Interactive)

📍 Location

playwright-report/index.html

🚀 How to Open

npm run test:report

✨ Features

  • Interactive web interface with modern UI
  • Visual test execution timeline
  • Screenshots captured on test failures
  • Video recordings of entire test runs
  • Trace viewer for step-by-step debugging
  • Filter tests by status (passed/failed/skipped)
  • Search functionality for quick navigation
  • Network activity monitoring
  • Console logs integrated
  • Test duration analytics

📄 Report Type 2: JSON Report (Machine-Readable)

📍 Location

test-results/results.json

🔍 View in Terminal

cat test-results/results.json | jq

💡 Use Cases

  • CI/CD pipeline integration
  • Custom dashboard creation
  • Automated alerting systems
  • Test metrics collection
  • Historical trend analysis
  • API integration with monitoring tools

📋 Report Type 3: JUnit XML Report (CI/CD)

📍 Location

test-results/junit.xml

🔗 Compatible CI/CD Tools

  • Jenkins - Standard JUnit plugin
  • GitLab CI - junit report type
  • Azure DevOps - Publish Test Results
  • CircleCI - Store test results
  • TeamCity - XML Report Processing
  • GitHub Actions - Test Reporter

🖥️ Report Type 4: Console Reporter (Real-Time)

📍 Location

Terminal/Console Output

📊 Real-Time Information

  • Live test execution progress
  • Pass/fail status for each test
  • Execution time per test
  • Detailed error messages
  • Console logs from tests
  • Summary statistics

🎯 Quick Commands

Command Description
npm test Run all tests and generate reports
npm run test:report Open HTML report in browser
npm run test:headed Run tests with visible browser
npm run test:ui Run tests in interactive UI mode
npx playwright test --debug Run tests in debug mode
npx playwright show-trace [file] View trace file for debugging
